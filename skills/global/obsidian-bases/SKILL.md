# Obsidian Bases Integration

## When to use this skill
Trigger when creating or managing `.base` database files within Obsidian vaults.

## Structure
Bases represent structured database views backed by YAML frontmatter properties across notes.
- Use explicit property types (`text`, `number`, `date`, `multiselect`, `checkbox`).
- Keep query filters predictable and folder-bound.
